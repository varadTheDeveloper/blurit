Blurit / Privacy

This page describes what Blurit's own code does. The code is open source, so you can check it.

What is stored

Your post
The text, the time it was posted, and how many times it has been reported. Nothing else. No name, no account, no device ID.
How long
48 hours. After that the post is deleted from the database.

What is not stored

IP addresses
Never written to the database. The server keeps them in memory for a short time only to limit posting speed and to stop the same person reporting a post twice. This memory is cleared at least once a day and whenever the server restarts.
Cookies and tracking
The feed sets no cookies and loads no analytics or third-party scripts.

Hosting

Like every website, Blurit runs on servers operated by a hosting provider, which may keep its own network logs. Blurit does not use those logs to identify anyone.

Contact

Questions about privacy can be asked on GitHub.
